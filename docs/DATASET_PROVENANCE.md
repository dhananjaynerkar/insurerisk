# Insurerisk dataset provenance

**Status: INPUT PROVENANCE NOT RECORDED IN THIS REPOSITORY**

The project expects these local input files:

- data/raw/insurance_data.csv
- data/raw/employee_data.csv
- data/raw/vendor_data.csv

The repository does not commit these raw files and the current README does not
record an upstream source URL, license, or redistribution permission for each
input. Before sharing any input, derived dataset, or generated report, record
the source, license, attribution requirement, and permission status.

## Safe handling rule

- Keep raw and generated data outside Git unless publication permission is
  explicitly confirmed.
- Do not replace the missing inputs with real personal or insurance records.
- Do not treat the sample outputs in the notebook as evidence of business
  impact.

## Reproduction record

For a reproducible run, record the commit SHA, input dataset versions, date
range, row counts, split boundaries, feature configuration, model artifact
version, and metric outputs. If an input or permission cannot be verified,
record the run as constrained rather than presenting it as production evidence.
